# workflow-find — search the toolset before working without it

The workflow toolset ships ~140 skills across several plugins. A session only
sees the descriptions of the plugins it has installed, so a fitting skill can
exist without you knowing. This skill closes that gap: search, then either use
the match or tell the user what to install. Searching is read-only and cheap,
so do it without asking.

## 1. Search

The search script lives in this skill's base directory (the path shown when
this skill loads). Run it with the user's task in their own words:

```
python3 "<base directory>/scripts/find.py" "<the task, in plain words>"
```

- `--limit N` widens the list (default 5); `--json` gives machine output;
  `--list` prints every entry.
- Exit 1 means no match: the toolset has nothing for this, so carry on
  without it and do not invent a skill.
- Try one rephrasing (a synonym, or the artifact name such as "PRD",
  "GDD", "test plan") before concluding there is no match.

## 2. Pick, do not dump

Read the top matches' descriptions and choose the single best fit for what
the user actually asked; mention a runner-up only if the choice is genuinely
close. Prefer a non-deprecated skill over one whose description says
DEPRECATED, and a general skill over a game-specific (`gds-*`) one unless the
project is a game.

## 3. Use it or name the install

- **The match is in your available skills list:** invoke it with the Skill
  tool and continue the user's task through it.
- **It is not installed** (each catalog match shows `[plugin: <name>]`):
  tell the user in one line which plugin carries it and the command, e.g.
  `/plugin install workflow-method@workflow`, then do what you can without it.
  Never claim you used a skill that is not loaded.

## Where the catalog comes from

In the published plugins, `catalog.json` beside this file is generated by
`wf plugin build` from the same allowlist the leak gate enforces, so it lists
exactly the public skills and the plugin that ships each one. Inside the
workflow repo itself there is no catalog; the script scans the sibling skill
directories live instead, so results always match what is on disk.
